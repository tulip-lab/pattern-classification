# M08 — Discriminant Functions

This module studies classifiers that learn a direct decision function. It
connects empirical loss and optimisation to linear separators, margins,
support vectors, and kernel decision boundaries.

## Learning outcomes

After completing this module, learners should be able to:

1. express a classifier as a discriminant function and decision rule;
2. relate an empirical objective and regularisation term to a learned boundary;
3. explain margin maximisation and the role of support vectors; and
4. compare linear and kernel SVMs using appropriately scaled data and
   validation evidence.

## Topic sequence

- **M08A — Classification and discriminants:** linear scores, decision
  surfaces, empirical risk, optimisation objectives, and regularisation.
- **M08B — Support vector machines:** margins, soft-margin classification,
  support vectors, kernels, hyperparameters, and model interpretation.
