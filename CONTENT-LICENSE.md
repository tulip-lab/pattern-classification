# Teaching content licence status

No new teaching-content licence is granted by this file. The repository needs a
confirmed owner decision before applying a licence to original narrative
teaching content.

The related Modern Data Science repository uses CC BY-NC-SA 4.0 for original
narrative content, which is a candidate for consistency, but it has not been
adopted here.

Third-party books, papers, slides, datasets, images, software, trademarks,
institutional policy text, and linked resources retain their own terms and must
be reviewed before reuse.
