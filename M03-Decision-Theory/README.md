# M03 — Bayesian Decision Theory

This module turns probabilistic beliefs into classification actions. It makes
the consequences of a decision explicit through loss, conditional risk, and
decision boundaries rather than treating maximum probability as the only
possible rule.

## Learning outcomes

After completing this module, learners should be able to:

1. calculate posterior class probabilities from priors and class-conditional
   likelihoods;
2. construct a Bayes decision rule for zero-one and asymmetric loss;
3. derive or visualise discriminant functions and decision boundaries; and
4. explain how priors, likelihoods, and costs change a classifier's decisions.

## Topic sequence

- **M03A — Bayesian decisions:** classification terminology, priors,
  likelihoods, evidence, posterior probabilities, Bayes' rule, and minimum
  error decisions.
- **M03B — Loss, risk, and boundaries:** loss matrices, conditional risk,
  minimum-risk decisions, discriminant functions, and the geometry of decision
  regions.
