# M01 — Course Induction

This module introduces the purpose, learning design, common-core structure, and
responsibilities that support successful study of Pattern Classification.

## Learning outcomes

After completing this module, learners should be able to:

1. locate common-core, practical, and offering-specific materials;
2. describe how theory, implementation, evaluation, and communication connect
   across the course;
3. identify expectations for accessibility, collaboration, academic integrity,
   responsible AI use, and safe handling of data; and
4. plan an appropriate learning pathway through the modules selected by their
   offering.
