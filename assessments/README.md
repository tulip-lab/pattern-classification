# Assessment index

Assessment design and delivery vary by institution and teaching period. The
common core defines assessment families and alignment principles in
[COMMON-CORE.md](../COMMON-CORE.md), but it does not define current tasks,
weights, dates, group rules, or submission channels.

Public offering-specific assessment briefs are indexed through
[offerings/](../offerings/README.md). Archived briefs are historical references
and must not be treated as current instructions.
