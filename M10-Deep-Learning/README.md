# M10 — Deep Learning

This module introduces representation learning for patterns whose useful
features are learned jointly with a classifier. It covers the shared training
mechanism before contrasting convolutional models for spatial data with
recurrent models for sequences.

## Learning outcomes

After completing this module, learners should be able to:

1. describe layers, activations, losses, backpropagation, and gradient-based
   parameter updates in a neural classifier;
2. diagnose underfitting, overfitting, and unstable training from learning
   evidence;
3. explain how convolution, pooling, recurrence, and gating encode different
   structural assumptions; and
4. design a fair baseline and evaluation protocol for a scoped deep-learning
   classification problem.

## Topic sequence

- **M10A — Deep-learning foundations:** multilayer networks, representation
  learning, activations, loss functions, and backpropagation.
- **M10B — Training and tuning:** initialisation, optimisation, batches,
  regularisation, validation, diagnostics, and reproducibility.
- **M10C — Convolutional networks:** local connectivity, shared filters,
  feature maps, pooling, and image classification.
- **M10D — Recurrent networks:** sequential state, recurrent computation,
  vanishing gradients, LSTM/GRU ideas, and sequence classification.
