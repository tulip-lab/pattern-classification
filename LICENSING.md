# Licensing and provenance

This repository must distinguish code from narrative teaching content:

- The repository currently contains a [Mozilla Public License 2.0](LICENSE)
  file. Its intended scope for future code should be confirmed before code is
  migrated from another repository.
- No new licence has yet been adopted for original narrative teaching content;
  see [CONTENT-LICENSE.md](CONTENT-LICENSE.md).
- Third-party resources, linked slide handouts, publications, datasets, logos,
  and images retain their source-specific terms.

A repository-level licence does not override third-party rights. A link is not
evidence that material may be copied into this repository. Before incorporating
an external artefact, record its source, author, licence, permitted use, and any
required attribution. Material with unclear ownership remains a link or stays
out of the public repositories pending review.
