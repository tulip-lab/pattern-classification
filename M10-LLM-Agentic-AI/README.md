# M10 — Large Language Models and Agentic AI

This module examines large language models and agentic AI as decision systems. It connects prompts, retrieved context, generated outputs, tool choices, and agent actions to Pattern Classification concepts including representation, decision rules, loss, uncertainty, validation, and failure analysis.

## Learning outcomes

After completing this module, learners should be able to:

1. explain how an LLM or agent converts context into outputs, tool choices, or actions;
2. formulate a scoped evaluation task with observable success, failure, and refusal outcomes;
3. compare an LLM or agent workflow with a controlled baseline using held-out cases and explicit measures;
4. inspect uncertainty, hallucination, tool-use errors, prompt sensitivity, and other failure modes; and
5. document model, provider, prompt, tool, data, and resource assumptions needed for reproducibility and responsible use.

## Topic sequence

- **M10A — LLM foundations:** tokens, context, generation, prompts, structured outputs, and model limitations.
- **M10B — Agentic decisions:** tools, routing, state, action validation, execution traces, and refusal behaviour.
- **M10C — Evaluation:** held-out task sets, baselines, behavioural measures, error taxonomies, robustness, and reproducibility.
- **M10D — Responsible operation:** privacy boundaries, prompt injection, provenance, cost, human review, and changing hosted-model behaviour.
