# M02 — Mathematical Foundations

This module establishes the probability and statistical language used to
describe uncertain observations, model parameters, and classification
decisions. Linear algebra and optimisation are treated as supporting tools and
can be selected according to the preparation of a particular cohort.

## Learning outcomes

After completing this module, learners should be able to:

1. represent events, random variables, conditional probabilities, and common
   distributions using consistent notation;
2. distinguish a likelihood, prior, evidence, and posterior distribution;
3. use expectation, variance, covariance, and matrix operations to describe
   multivariate pattern data; and
4. identify where estimation and optimisation enter a classification
   workflow.

## Topic sequence

- **M02A — Probability and statistics:** events, conditional probability,
  Bayes' rule, random variables, expectation, variance, covariance, and common
  distributions.
- **M02B — Bayesian methods for machine learning:** prior information,
  likelihood, evidence, posterior inference, predictive reasoning, and the
  modelling assumptions that connect them.
- **Supporting preparation:** vectors, matrices, linear models, matrix
  factorisation, and elementary optimisation as required by the offering.

## Practicals

[Lab M02A — Classification workflow and features](https://github.com/tulip-lab/pattern-classification-lab/tree/develop/M02-Foundations)
uses a leakage-safe pipeline to connect mathematical quantities to features,
model fitting, validation, and a held-out evaluation. It prepares learners to
reason about assumptions before M03 introduces explicit loss and risk.
