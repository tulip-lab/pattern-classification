# Pattern Classification Common Core

## Purpose

The common core provides reusable learning content for multiple institutions
and teaching periods. It defines a coherent disciplinary progression without
claiming institution-specific workload, policy, assessment weight, or dates.

## Course learning outcomes

After completing the relevant modules, learners should be able to:

1. **Explain** uncertainty, loss, risk, and decision boundaries in Bayesian
   pattern classification.
2. **Estimate** model parameters and probability densities using appropriate
   parametric, nonparametric, and stochastic methods.
3. **Implement and compare** selected generative and discriminative classifiers
   for appropriately scoped data problems.
4. **Evaluate** classification systems using suitable validation designs,
   metrics, error analysis, and evidence about uncertainty and limitations.
5. **Design and communicate** a reproducible pattern-classification solution,
   including justified modelling choices and clear interpretation of results.
6. **Assess** privacy, fairness, provenance, responsible AI use, and other risks
   arising in the collection, modelling, and communication of pattern data.

## Module map

| Module | Learning contribution | Primary outcomes |
| --- | --- | --- |
| M01 Induction | Learning model, integrity, accessibility, collaboration, and offering navigation | CLO5, CLO6 |

| M09 Model Evaluation | Validation, metrics, comparison, and generalisation | CLO4 |
| M10 Deep Learning | Representation learning for image and sequence patterns | CLO3, CLO4 |
| M11 Privacy | Privacy risks and privacy-aware analysis | CLO6 |

## Constructive alignment

The common core defines assessment families rather than fixed weights. Each
offering must publish its actual tasks and alignment.

| Assessment family | Direct evidence | Aligned outcomes |
| --- | --- | --- |
| Concept explanation or presentation | Accurate synthesis, comparison, and oral or visual communication | CLO1, CLO5, CLO6 |
| Applied classification project | Reproducible workflow, justified methods, implementation, and results | CLO2, CLO3, CLO4, CLO5, CLO6 |
| Technical report and reflection | Evaluation evidence, limitations, provenance, responsible-use decisions, and clear communication | CLO4, CLO5, CLO6 |

Where possible, learners should receive formative feedback on a proposal,
baseline, or evaluation plan before the highest-stakes submission.

## Learning and assessment principles

- Activities should include explanation, worked analysis, implementation,
  evaluation, and reflection rather than rote reproduction.
- Public practicals should offer accessible instructions and a reproducible
  online or local execution path where applicable.
- Offerings must state permitted collaboration and AI assistance, required
  acknowledgement, and any constraints using their approved policy sources.
- Assessment data must be public, approved, safely synthetic, or otherwise
  appropriately authorised for the offering.
